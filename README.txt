ASISTENT CÂNTĂRI – PACHET PENTRU IPHONE

1. Încarcă TOATE fișierele din acest folder într-un repository GitHub public.
2. În GitHub: Settings > Pages.
3. La Build and deployment, alege Deploy from a branch.
4. Branch: main; Folder: / (root); Save.
5. Așteaptă publicarea, apoi deschide adresa HTTPS pe iPhone în Safari.
6. Apasă Share > Add to Home Screen > Add.

Notă: recunoașterea vocală depinde de browser și de permisiunea microfonului.
Datele introduse în aplicație se păstrează local în browserul dispozitivului.
